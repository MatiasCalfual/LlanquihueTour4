## Semana 7 – Aplicando polimorfismo y colecciones genéricas

### Funcionalidades implementadas

- Se agregó el método `mostrarInformacion()` en la clase `ServicioTuristico`.
- Se sobrescribió este método en las clases `RutaGastronomica`, `PaseoLacustre` y `ExcursionCultural`.
- Se creó la clase `GestorServicios` en el paquete `data`.
- Se implementó una colección `List<ServicioTuristico>` para almacenar distintos tipos de servicios turísticos.
- Se recorrió la colección mediante un ciclo `for-each`, aplicando polimorfismo para mostrar la información específica de cada servicio.

### Cómo ejecutar

1. Clonar el repositorio.
2. Abrir el proyecto en NetBeans o IntelliJ IDEA.
3. Ejecutar la clase `Main` ubicada en el paquete `ui`.
